# 013 Themes plan

1. **Packages.** `shiki` and `@shikijs/monaco` as dev dependencies at their latest stable version. Proof, `npm ls`.
2. **The list and the mapping.** `src/shared/themes/curated-themes.ts` lists each theme from the highlighter's theme package with its name, credit, site and state keys. `src/shared/themes/theme-look.ts` checks colours in one strict hex form and maps a theme to the app tokens, the terminal, the editor theme and the overlay. Proof, `theme-look.test.ts`, every curated theme mapped fully, hostile values refused, and every pair the mapping makes measured against the bar, with the theme's own pairs below it listed.
3. **The choice.** `themeChoice` in `src/shared/bridge-contract.ts` gains the curated ids from the list, `src/main/state/interface-file.ts` reads an unknown theme as System. `src/main/main.ts` and `src/main/window/main-window.ts` set `themeSource` from the theme's type, the window's background and the overlay through `src/main/platform/title-bar.ts`. Proof, `interface-file.test.ts` and `title-bar.test.ts`.
4. **The page.** `src/renderer/ui/shown-theme.ts` sets the tokens on the root before the first render and on every change and tells the terminal and the editor. `app.css` gains `working` and `danger`, the components that meant those states read them, and the one raw colour goes. Proof, the verify driver in every main view.
5. **Syntax.** `src/renderer/diff/syntax-worker.ts` runs Shiki in a worker within the bounds of `bounded-tokens.ts`, one highlighter per curated theme, each grammar when its language first shows, and `src/renderer/diff/theme-syntax.ts` looks its lines up on the page, gives Monaco the theme's own editor theme, and gives Monaco's tokenizers back on leaving. `src/renderer/terminal/terminal-theme.ts` takes the theme's terminal colours. Proof, `bounded-tokens.test.ts` and journey `hostile-file`.
6. **Settings and commands.** The theme select, the credit with its link and a command per curated theme from the list. Licence notices from `scripts/third-party-licenses.ts`. Proof, journey `settings`, `npm run package` and the notices file.
7. **Journeys.** Journey `settings` proves a curated theme chosen in Settings taking the window and kept after a relaunch. Proof, `npm run --silent journeys`, and the packaged app on macOS.
8. **Docs.** `DESIGN.md`, `ARCHITECTURE.md`, `SATELLITE.md`, skills `satellite-conventions`, `satellite-stack` and `satellite-verify`, spec 012.
9. **Acceptance on each system.** A person sees the dark frame and overlay on each system, then the spec turns Done and this plan goes.
