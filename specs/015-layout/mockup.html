the agent at the centre
everything else one glance away

SPEC 015 · DRAFT

A new shape for Satellite. Your Claude Code session takes the middle of the window, a slim rail on the right answers one question, what still blocks this pull request, and the sidebar tells you which agent needs you. Fewer surfaces, denser controls, nothing that redraws GitHub.

00

what is wrong today

Read against the current build and the research on what people who run parallel agents keep using and what makes them quit. The verdict is that the shape fights the job. The thing you watch all day sits in a side column, the thing you glance at sits in the middle.

01

The agent is a side panel

Claude Code is where the work happens, yet it gets 440px on the right while the centre shows a file tree you open now and then. People who stay with these tools use the agent's own terminal all day.

02

The pull request tab mirrors github.com

Overview, Checks, Conversation and Files copy a website that will always be better at being itself. It answers nothing the browser does not, so it reads as useless.

03

Chrome before content

A 22px wordmark, three boxed command rows with key caps, an uppercase label and a 40px title bar take 330px before the first repo. Empty states float in a sea of white.

04

Controls feel heavy

Boxed key hints everywhere, borders on every control, two segmented controls in one bar, three header readouts. Weight sits on what matters least.

05

No sense of done

Status tells you working or needs you, never "this one is ready to ship". That is the question people with five agents actually ask.

06

One flat plane

Three equal columns on one ground give no hierarchy. Nothing says where to look first.

A

Agent in the middle

The real Claude Code, untouched, on its own raised surface. Session tabs on top. Click a repo and every agent in it is live at once.

B

A rail that answers one question

Changes, Files and Ready as icon tabs on a 348px rail. Ready replaces the pull request mirror with what still blocks the merge and one send per blocker.

C

A sidebar that triages

Needs you on top, then repos. Every workspace row carries its pixel and its ship state, so the window works at a glance.

01

The title bar is gone as a strip, the traffic lights share the sidebar's top row and the header names the workspace.

13

the version to build

One feature, Layout, shipped in five pull requests that each leave the app better on their own. Every one keeps the principles. Real Claude Code, real git and gh, no credentials held, nothing written into the repository, nothing read from what a session prints.

What people need, and the answer here

  • The real agent, rendered well. Claude Code untouched in the centre, the largest surface in the window.
  • Every agent of a repo at once. Click the repo, see them all live, answer in place.
  • Knowing which agent needs them. Needs you on top of the sidebar, orange for nothing else, Cmd+J to jump there.
  • Knowing what still blocks a merge. Ready lists it, honestly, and leaves the merge to you on GitHub.
  • Light and calm. Three rail tabs instead of four GitHub sections, no board, no browser, no chat wrapper, no search the agent already does.

Overlay rule

  • A page for anything with sections or forms. Settings, Agents, New workspace, a full diff, a file.
  • A dialog only for one quick decision. Archive or remove a repo with something to lose, quit while agents run, open a link or a port.
  • A popover for a short list tied to its control. Running processes, a picker, a menu.
  • The command menu on Cmd+K is the one overlay you summon, workspaces and commands in one list.
  • A page that covers the sidebar still lets a needs you through as a toast.

PR 1

Agent in the centre

Grounds, centre surface, header, session tabs. Changes and Files move into the rail, a file or diff opens as a centre tab. Repos in the sidebar. Kit controls and key hints.

PR 2

Ready

The Pull request tab becomes Ready, built from what gh already returns. Overview, Conversation and Files go. Cmd+J jumps to what needs you.

PR 3

Pages

Settings as a full window page, Agents and New workspace as centre pages, running processes as a popover.

PR 4

Repo view

Click a repo for every live agent at once, Grid and Focus, focus keys, fill the centre.

PR 5

Docs and polish

DESIGN.md and SATELLITE.md say what shipped, BRAND.html kit redrawn, journeys updated, light and dark proof.

WEIGHT

Budget

Only visible tiles draw a terminal, strip cells are state. Nothing new polls gh. Six live sessions stay as smooth as one.

ASK FIRST

Decisions only you can take

The layout itself and the rewrite of SATELLITE.md and DESIGN.md. Ready replacing the Pull request tab. New workspace passing your request to Claude Code as its first message. Cmd+J moving to Go to what needs you. Taking over the title bar from spec 011.

LEFT OUT ON PURPOSE

What we will not build

A chat UI over Claude Code, content search, merge buttons, bot approvals, bulk archive, a board, a browser, automations, cloud runners, other agents for now, an editor, a commit box. Each one is either something the agent already does, a risk to your repository, or weight people told us made them leave.
