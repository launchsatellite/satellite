00 · Principles

Spacecraft software, built from code

Satellite looks like the instrument panel of an advanced craft. Everything is made from the same pixel, the same glyph grid and a handful of flat colours.

Flat, always

Solid colour, no gradients, shadows, glow or glass. The art keeps hard pixel edges, the tools get soft corners.

One pixel

The square pixel is the atom. Logo, status, art and readouts are all built on it, so every surface feels like one machine.

Black and white first

Around ninety percent of any screen is black, white and grey. Colour is rare, so it always means something.

One signal

Signal orange means an agent needs you, and nothing else. It is the loudest pixel on screen.

01 · Logo

one planet
two paths

Twin is a pixel planet with two rows slipping in opposite directions, like branches leaving main to work side by side. Seen small it reads as a satellite with its panels out. The wordmark is Funnel Display 700, always lowercase.

Clear space

Keep one row height of the mark empty on every side. Nothing else enters that frame.

Small sizes

Never below 12px. At 16px and under it snaps to whole pixels, so every row stays crisp.

Colour

One flat colour. Paper on void, void on paper, white on ultraviolet. Never two colours inside the mark.

Motion

While agents work the two rows slip apart, and they close when the work lands. Pixel steps only, no easing.

App icon · mosaic edition

The icon is one fixed artwork and never changes. The exact Twin sits on a clear plate, like content in the hero, inside a hand-placed mosaic frame. One unit runs through it all, each Twin pixel is one mosaic block, so every tile lines up with the mark and the edges. Ultraviolet leads, volt gathers at the bottom, lilac runs along the sides and one orange block sits top right, one agent that needs you.

02 · Mosaic

a field of agents
around your work

The mosaic is our signature texture. A grid of code characters where some cells light up as solid tiles, slowly changing like agents at work. It frames the content and never covers it.

{Glyph · a code character at 60% of the cell Tile · a solid cell with its glyph on top Block · tiles pick their colour per 2×2 block Signal · at most 1%, only for needs you
Dark mix

50 glyph · 24 paper · 12 ultraviolet · 6 grey · 4.5 lilac · 2.5 volt · 1 signal

Light mix

52 glyph · 22 void · 12 ultraviolet · 6 mist · 4 lilac · 3 volt · 1 signal

Frame, never fill

Content gets a clear zone two cells wide on every side. Headlines and windows always sit on empty ground.

Blocks of four

Colour is picked per 2×2 block, so the shapes stay chunky and read from across the room.

Slowly alive

About one block in eight changes every few seconds. With reduced motion the field holds still.

Signal is rare

Orange covers at most one cell in a hundred. One spark of something that needs you.

Themes invert

Light is void on paper, dark is paper on void. Ultraviolet, lilac and volt stay the same in both.

Product in a bezel

The app window sits in a solid frame of the opposite tone. 10px wide, 22px outside and 12px inside.

Cells 16 to 18px

On screen at 1×. Posters and slides scale the cell, never the mix.

Characters from code

Brackets, operators and hex in Geist Mono. Never letters that spell words.

Projects

one setup for
every workspace

Each project has a setup command, a cleanup command and a list of files to copy. Every new workspace is made the same way, and your repository is never touched.

files to copy

Files git ignores but your project needs, like a local config, are listed in a .worktreeinclude file at the root of the project. It is the same file Claude Code reads and it uses gitignore syntax.

.worktreeinclude# copied into every new workspace
local.config.json
certs/localhost.pem
Good to know

Commands and settings live in Satellite's own folder on your Mac. Opening a project writes nothing into it.

ports

Every workspace gets its own free port, so two branches can run side by side. Read it from SATELLITE_PORT and the Browser tab opens the right address.

SATELLITE_PORTA free port for this workspace, kept until it is archivedSATELLITE_WORKSPACEThe workspace name, like fix-login-redirect
Careful

The cleanup command runs before the worktree is removed. Keep it quick and safe to run twice.

08 · Kit

every part
built from the pixel

The pieces the app and the site are made of, smallest first. Every component reads only semantic tokens, so each one is drawn once and works in dark and light. Build from this page and the screens stay consistent.

Tokens

Name the job, never the colour

Components never use a raw hex. They ask for a role, like line or raised, and each theme answers. Brand colours stay the same in both themes, so ultraviolet and signal always mean the same thing.

Spacing

A 4px grid. Gaps inside a control use 4 to 8, between controls 8 to 12, between groups 16 to 24, between sections 32 and up.

Control heights
24283236

24 for dense rows and small buttons, 28 is the default control, 32 for inputs, 36 for the main action of a dialog.

Depth
bgsideraised

Depth comes from three surfaces and hairlines. Only floating things, menus, the palette and dialogs, cast a shadow.

Motion
steps · 120ms · 200ms

Pixels move in steps, never glide. Hover and press take 120ms, panels and menus 200ms. With reduced motion everything stands still.

Atoms

The smallest pieces

One square pixel for status, one control height, one focus ring. Corners are 2 on pixels, 4 on tags and keys, 6 on controls, 8 on inputs.

Workspace · Changes

review while it works

The diff is the main view. Comment on any line and the comment lands in the prompt of the Claude Code session next to it, ready to send. The pull request your agent opens is one tab away.

Inbox

every agent, one list

Agents that need you come first, across every project. A question from Claude Code, failed checks or a conflict all count. Pick a row and its session opens on the right, so you answer in Claude Code itself.

All agents · Board

the whole fleet at a glance

Every workspace in every project, sorted by what it needs. Each card carries its Git state, checks as three pixels and a two hour activity strip, ultraviolet while it works and orange while it waits on you.

Workspace · Pull request

GitHub without the tab

Checks, reviews and merge for this branch. A review comment goes to Claude Code in one click, and Satellite warns when main moves ahead before it becomes a conflict.

Pull request · Checks failed

red check, one click

The failing check opens on its own errors, not a wall of log. Send them to Claude Code and the errors and a link to the full log land in its prompt. The fix arrives as a new commit on the same branch.

Changes · Conflicts

main moved, nothing broke

Updating from main is a first-class moment with its own band. Each conflict shows yours and main side by side with four answers. Ask Claude Code writes the request into its prompt, you read it and press enter.

Workspace · Browser

see it running

Every workspace runs on its own port, so two branches can run side by side. Pick an element and ask about it, the question goes to Claude Code with the selector attached.

Workspace · Files

read it, then open your editor

A fast file view with Git letters in the tree and the lines this workspace changed marked in ultraviolet, with who changed them. Satellite is for reading and reviewing, your own editor is one click away for the rest.

Sessions and history

more than one claude per room

A workspace can run several Claude Code sessions side by side, one planning and one writing tests. New, continue and resume use Claude Code's own sessions. Changes by commit shows what is already on GitHub and what is not.

Glossary

One word for one thing

The same names in the app, the docs, the site and every pull request.

Project

A repository you added. It holds workspaces.

Workspace

One task. A worktree, its branch, its Claude Code sessions and its port.

Session

One run of Claude Code inside a workspace. A workspace can have several.

Inbox

Everything across projects that needs you, ready to review or working.

Needs you

An agent can't go on without you. A question, failed checks, a conflict or requested changes.

Ready

Checks passed and the pull request waits for a review or a merge.

Update from main

Bring main's new commits into the branch, by merge or rebase as the project prefers.

Archive

Remove the worktree and stop its servers. The branch stays unless it is safe to delete.
